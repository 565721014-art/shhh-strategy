# 58 篇国一论文反推的赛题分析思考手册

> 研究边界：58 篇不重复国一论文，覆盖 23 道原题（2020A、2020C、2021A—E、2022C、2023A—E、2024A—E、2025A—E）。分析单位始终是“原题”，同题论文用于比较共识与分歧；六类题型只用于提炼分支规则。

## 一、最重要的结论

不存在一套能把所有题都变成同一个模型的“万能算法”。能够跨 23 道题稳定复用的，是一套**不允许关键环节缺席的分析纪律**：

**交付物 → 语义 → 边界与信息 → 数据结构 → 变量角色 → 问题依赖 → 母模型 → 数学闭合 → 求解路线 → 验证与表达。**

这套主线不规定必须使用回归、规划、微分方程、神经网络或启发式算法。它规定的是：在选算法前，必须先回答哪些问题；在给结果后，必须怎样证明结果没有明显失真。

因此，“全部适用”的正确含义是：

- 主流程覆盖所有赛题；
- 不同题型在主流程中进入不同分支；
- 遇到新题时先判断数据和系统结构，再选择分支；
- 任何分支都必须重新回到同一套验证闭环；
- 国一论文是高质量参照，不是天然无误的标准答案。

## 二、比赛拿题后的十步闭环

### 第 0 步：先锁定交付合同

暂时不想模型，先逐问抄出：

1. 要输出什么：数值、排序、分类、曲线、路径、策略、参数、附件文件还是解释；
2. 输出对象是谁：每个企业、每周、每块地、每条测线、每个矿工还是总体；
3. 时间、空间、单位、精度和文件格式；
4. 是否要求“分析影响”“检验显著性”“评价方案”“给出建议”；
5. 后一问是否必须使用前一问的模型或结果。

这一动作能拦住最常见的低级错误：模型做得很复杂，却漏交结果文件、漏答影响分析、对象粒度不对或单位错误。

### 第 1 步：翻译动词、量词和优先级

把自然语言逐句翻成数学语言：

| 原题词语 | 首先检查的数学含义 |
|---|---|
| 至少、不超过、必须、不能 | 硬约束 |
| 尽量、尽可能、兼顾 | 目标或软约束，需说明权衡 |
| 首先……其次…… | 可能是字典序目标，不能随意加权 |
| 每个、任意、始终 | 全称约束，不能只检查平均值或采样点 |
| 首次、最早、达到后 | 首达时刻、事件检测或生存过程 |
| 连续、相邻、轮作、间隔 | 跨期/跨对象耦合约束 |
| 实时、调整、发生后 | 状态更新和滚动重优化 |
| 影响、原因、措施效果 | 不自动等于相关性，需要因果边界 |

圈出题目中所有“否定词、比较词、时间词、全称量词”。它们往往比算法名更决定模型。

### 第 2 步：画系统边界和信息时点

回答四个问题：

1. 系统内有哪些对象，哪些关系跨对象发生？
2. 状态如何随时间或空间演化？
3. 做决策时已经知道什么，未来什么仍未知？
4. 哪些结果可以被决策改变，哪些只是观测？

特别检查信息泄漏：预测未来时不能使用未来数据；按人划分的重复样本不能同时进入训练和测试；决策模型不能使用实施决策后才能出现的信息。

### 第 3 步：做数据与对象结构审计

在清洗前先判断数据是什么：

- 横截面、时间序列、面板/重复测量、实验设计、网络、轨迹、图像/光谱、成分数据还是空间场；
- 一行代表人、一次检测、一天、一个企业、一个节点还是一个事件；
- 缺失、零值、异常值是错误、检测下限还是有实际意义；
- 是否存在固定总和、单位尺度、层级、相关样本、删失或不平衡；
- 附件间的主键、时间戳、坐标系和单位是否一致。

先做这一层，才能避免把 2022C 的成分百分比当普通独立变量、把 2025C 的多次检测当独立孕妇、把 2025E 的像素距离当米。

### 第 4 步：建立变量角色表

不要把所有符号混在一起。至少分成：

| 角色 | 含义 | 典型例子 |
|---|---|---|
| 给定参数 | 题目或外部知识给定 | 几何尺寸、速度上限、成本 |
| 观测量 | 附件直接测到 | 温度、销量、光谱反射率、坐标 |
| 状态量 | 随时间/空间演化 | 库存、水位、位置、温度场 |
| 决策量 | 方案可以控制 | 价格、路线、投放时刻、种植面积 |
| 待估参数 | 需要由数据反演 | 传热系数、厚度、弹性系数 |
| 不确定量 | 决策时未知 | 需求、供货率、次品率、误差 |
| 输出指标 | 用来评价或提交 | 利润、风险、命中率、遮蔽时长 |

若一个量同时扮演两个角色，必须解释发生在哪个阶段。例如销量在历史数据里是观测量，在未来补货中只能是含不确定性的结果量。

### 第 5 步：画问题依赖图，找到母模型

不要把各问当成四道互不相干的小题。先问：

- 哪一问建立基本关系？
- 后一问改变的是参数、目标、约束、对象数量、信息条件、尺度，还是不确定性？
- 哪个计算引擎应该只写一次并复用？

国一论文中最稳的结构通常是：

1. 第一问建立可计算的母模型；
2. 第二问校准、优化或把母模型变成决策；
3. 第三问扩展对象、情景或约束；
4. 最后一问进入大规模、实时、随机或综合应用。

若每一问都换一种无关算法，要高度警惕论文只是“算法拼盘”。

### 第 6 步：让模型数学闭合

至少写清：

1. 输入；
2. 状态或中间关系；
3. 输出；
4. 初始条件/边界条件；
5. 目标函数；
6. 硬约束；
7. 不确定性与观测误差；
8. 未知参数如何识别。

做四项闭合检查：

- **量纲闭合**：等式两侧单位一致；
- **变量闭合**：每个未知量有方程、数据或约束支撑；
- **因果/时间闭合**：输入在需要它的时点确实可知；
- **范围闭合**：所有物理边界和业务边界都被表达。

### 第 7 步：先基线，再升级，再选求解器

正确顺序是：模型结构 → 可解性 → 算法。

1. 给出一个可解释、可运行的基线；
2. 找出基线违反了哪项关键结构；
3. 只为解决该缺陷而升级模型；
4. 根据连续/离散、凸/非凸、维数、实时性选择求解器；
5. 启发式算法必须有小规模精确解、不同算法或重复运行作为参照。

不要用“模型高级”替代“问题对应”。随机森林、LSTM、遗传算法、粒子群等名字本身不构成建模贡献。

### 第 8 步：求解前就设计验证

验证不是最后补一段“模型较好”。每个核心模型至少从以下层次选两到四项：

1. **代码/算术验证**：手算样例、已知特殊情形、独立程序复算；
2. **结构验证**：守恒、边界、极端情形、单调性、事件完整性；
3. **数据验证**：留出集、滚动回测、按主体分组交叉验证；
4. **方案验证**：逐条约束复核、仿真重放、最坏情景；
5. **稳健性验证**：误差传播、参数敏感性、场景扰动；
6. **替代路线验证**：解析法与数值法、两算法或两角度结果交叉印证。

验证指标必须对准任务：分类准确率不能证明决策利润最优；拟合优度不能证明因果解释；平均覆盖率不能证明所有位置无漏测。

### 第 9 步：把推理写成可审计的论文

每一问的问题分析不应复述题干，而应回答：

1. 本问的本质对象是什么；
2. 继承前文什么；
3. 新增什么变量、约束或不确定性；
4. 为什么选择该模型；
5. 如何求解与验证；
6. 最终交付什么。

同一逻辑可以有不同写作风格：

- **机理递进式**：从物理过程、守恒或几何关系逐层推导；
- **决策闭环式**：从预测/评估到目标、约束和可执行方案；
- **事件链式**：按状态变化、触发事件和在线更新书写；
- **证据比较式**：先基线，再指出不足，用对照实验说明升级价值；
- **风险分层式**：先定义风险，再建概率模型和阈值/时点决策。

因此可复用的是段落功能，不是固定句式。

## 三、比赛前 30 分钟的最小工作产品

建议由论文负责人组织队伍共同完成“五张表、两张图、一份红线清单”。

### 五张表

1. **交付物表**：每问输出、单位、粒度、文件和验证要求；
2. **变量角色表**：给定、观测、状态、决策、待估、不确定、输出；
3. **数据结构表**：主键、时间、单位、缺失、层级、泄漏风险；
4. **约束表**：硬约束、软约束、优先级、来源和检验方式；
5. **候选路线表**：母模型、基线、升级点、求解器、验证。

### 两张图

1. **问题依赖图**：各问如何继承和扩展；
2. **系统流图**：输入—状态—决策—输出—反馈。

### 一份红线清单

- 单位或坐标系尚未统一；
- 决策时使用了未来信息；
- 重复样本发生训练测试泄漏；
- 全称约束只按平均值或稀疏采样检查；
- 目标和约束混淆；
- 风险评分被直接当概率；
- 相关性被写成因果；
- 后一问没有继承前一问的有效结构；
- 只有启发式结果，没有基线或复算；
- 结果文件与正文数值不一致。

## 四、六类题型的分支规则

### A. 机理、工程与反演

适用：2020A、2021A、2023A、2025B。

必须补充检查：

1. 先写守恒、几何、光学或传热机制，再离散；
2. 区分状态变量、物理参数和可控工艺变量；
3. 校准集与验证集分开，多工况/多角度共同反演优于单曲线过拟合；
4. 检查参数可辨识性：不同参数组合是否给出相同输出；
5. 先验证正向模型，再做反演和优化；
6. 用量纲、极端状态、残差结构和多方法交叉验证。

### B. 实验响应与设计

适用：2021B，也可迁移到所有带实验补点的题。

必须补充检查：

1. 因素、水平、重复、区组和实验批次；
2. 主效应、交互作用和温度/剂量响应；
3. 不把非随机观测轻易解释为因果；
4. 优化只在实验支持域内可信；
5. 新实验应区分“探索未知区域”和“确认候选最优点”；
6. 最优条件要给预测区间并由补充实验验证。

### C. 数据预测与经营决策

适用：2020C、2023C、2024B、2024E。

必须补充检查：

1. 标签、时间窗和可用信息；
2. 观测销量、真实需求、价格和缺货之间的关系；
3. 预测模型输出能否进入决策模型；
4. 决策目标、容量/预算/服务约束和风险偏好；
5. 预测误差、参数不确定性是否向决策传播；
6. 措施效果评价是否需要反事实而非简单前后对比。

### D. 多期资源配置

适用：2021C、2024C。

必须补充检查：

1. 决策索引覆盖对象×时间×资源；
2. 库存/土地/产能等状态转移方程；
3. 每期约束与跨期约束分开；
4. 评价排序不能代替资源配置；
5. 不确定量的相关性和场景生成方式；
6. 先找可行解，再谈最优；最后逐项复核所有年度和对象约束。

### E. 空间、动态与路径

适用：2021D、2023B、2023D、2024A、2024D、2025A、2025D。

必须补充检查：

1. 坐标、方向、角度、坡面和参考系统一；
2. 写清运动/传播/占用的状态更新；
3. 连续时间事件不能只靠粗网格采样；
4. 碰撞、覆盖、命中、遮蔽要定义完整几何判据；
5. 多路径/多对象的重叠区间不能重复累计；
6. 新事件发生后，从当前真实状态重算，不能从初始位置重来。

### F. 识别、时序与风险

适用：2021E、2022C、2023E、2025C、2025E。

必须补充检查：

1. 预处理必须只由训练数据拟合；
2. 划分单位应是人、样品或时间块，而非随意拆行；
3. 信号、成分、轨迹和重复测量各有专门结构；
4. 首达时间不能被“第一次观测达标”简单替代；
5. 分类概率、阈值和实际风险决策分开；
6. 预测、关联、机制解释和干预效果使用不同证据强度。

| 2025A | 多运动体轨迹—完整遮蔽判定—多弹多机调度 | 只查视线过云心，重叠时长重复累计 | 完整几何、区间并集、组合分层 | 稠密/事件检测、区间并集、算法复算 |
| 2025B | 双光束机理—光谱反演—多角度一致性—多光束判别 | 波数波长混用、忽略色散、无判据地换模型 | 机理分支、参数识别、模型诊断 | 双角联合、残差频谱、双/多光束比较 |

| 2025E | 关键点校验—阶段分割—动作特征—训练效果—个体建议 | 像素当实际距离、按帧泄漏、相关当训练因果 | 尺度/主体粒度、干预证据、迁移边界 | 按运动者验证、事件人工核验、建议区间 |

反测结论：十步主线在 23 题中均有落点；真正变化的是第 3、6、8 步的题型分支和验证方式。因此不能把六类合并为一个算法库，但可以由同一分析操作系统调度。

## 六、从 58 篇论文中提炼出的共识与分歧

### 稳定共识

1. 强论文通常先抽象对象关系，再介绍算法；
2. 第一问常承担“计算引擎”角色，后续通过继承扩展；
3. 结果表格只是终点，过程中的约束和检验决定可信度；
4. 同题不同论文可以使用不同算法，母问题和关键约束却应相近；
5. 物理/几何题依靠不变量与交叉计算，数据题依靠防泄漏与样本外验证，规划题依靠可行性和场景检验；
6. 最好的创新不是堆算法，而是发现题目的特殊结构并把它用于建模或降维。

### 不能照抄的分歧

1. 同题国一结果可能不一致，尤其是复杂几何、启发式优化和 OCR 难辨的公式页；
2. 有些论文以相关性支持“影响”，证据强度不够；
3. 有些论文使用复杂学习器，却没有严格主体外或时间外验证；
4. 有些启发式方案缺少全局最优保证或精确基线；
5. 有些随机模型只做敏感性分析，没有把误差传播到最终决策；
6. 有些论文摘要写得很强，但正文约束、数据划分或结果一致性仍需审计。

学习国一的正确方式是复制其“识别结构—建立闭环—层层扩展”的能力，同时用上述红线检查修正可能的漏洞。

## 七、赛场上的三轮检查

### 第一轮：结构检查（建模前）

- 每问交付是否明确；
- 对象、主键、坐标、单位是否明确；
- 状态、决策、观测、参数是否分开；
- 问题依赖和母模型是否明确；
- 硬约束、软约束和优先级是否明确。

任一项为“否”，不要急着上算法。

### 第二轮：对抗检查（得到结果后）

主动设计能让模型失败的情形：零输入、上限、极端坡度、供应骤降、误差放大、新事件、缺货、重复样本、边界位置。检查是否违反物理、业务或题意。

### 第三轮：一致性检查（提交前）

- 摘要、正文、图表、附件结果一致；
- 公式下标、单位、符号定义一致；
- 所有约束能从代码结果中逐项审计；
- 每个结论的证据类型正确：相关、预测、因果、机制不混写；
- 所有图表都有结论，所有结论都能回到原题、数据或模型；
- 结果保留精度和文件模板完全符合要求。

## 八、12 个“不过关就停止”的问题

1. 我们能用一句话说清母问题吗？
2. 每问的交付对象和粒度清楚吗？
3. 做决策时可知信息与未来信息分开了吗？
4. 数据的一行到底代表什么？
5. 状态量、决策量和待估参数分开了吗？
6. 所有硬约束都可由程序逐条检查吗？
7. 后一问确实继承了前一问的有效结构吗？
8. 模型的输入—状态—输出是闭合的吗？
9. 单位、坐标和时间基准统一吗？
10. 基线和复杂模型的差异能用一句话解释吗？
11. 验证指标与题目真正目标一致吗？
12. 摘要、正文和附件能由另一名队员独立复算吗？

只要其中任何一项回答含糊，就把它登记为显式风险，而不是用“合理假设”掩盖。

## 九、如何训练成自己的能力

每道题使用三遍训练法：

1. **盲读 30 分钟**：只看原题，完成五表两图；
2. **同题对照**：同时阅读该题所有国一论文，记录共识、分歧、漏项和验证；
3. **脱稿重写**：关闭论文，重新写一版问题分析和母模型；再用 12 个停止问题评分。

建议评分（100 分）：交付完整 10、语义与约束 15、对象和数据结构 15、母模型与问题依赖 20、数学闭合 15、验证 15、表达与可复算 10。低于 80 分不得进入算法堆叠阶段。
