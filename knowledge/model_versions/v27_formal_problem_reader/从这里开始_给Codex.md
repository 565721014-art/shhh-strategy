# 从这里开始：V27新题唯一入口

## 使用目标

收到任意新数学建模赛题后，先独立读懂题目，再选择方法。禁止先搜索同题答案、禁止凭题名联想模型、禁止重读全部历史论文，也禁止把历史论文的模型名称替代新题推理。

## 最小读取链

按顺序读取以下两层：

1. 完整执行 [v26入口与基础协议](../v26_post_23_iteration_frozen/从这里开始_给Codex.md)，包括其指向的事实锁定、深度审计、冲突处理、组件选择和输出规范；
2. 再读取 [V27增量规则](../../AI时代读题训练/v27_candidate_rules.md)，把其中目标适定性、混杂事件、轨迹约束、政策反馈、暴露分母、逆问题分层、政策生成标签、实验单元/派生特征、接触模式和结构干预分解加入优先审计。

上述链条是“完整继承v26 + V27增量”，不得只读V27的几条新增规则后跳过v26细粒度红线。

## 新题执行顺序

1. **材料完整性。** 读取所有题面页、图片、公式、脚注、表注、附件、数据字典和提交模板。对图片中的结构、箭头、坐标、遮挡关系和表格跨页关系形成文字化事实；缺失材料分为已确认、合理推断、待确认。
2. **先锁问题。** 对每问写出对象、输入、决策时点、可用信息、状态、决策、硬约束、目标、输出字段和评价口径，画出分问依赖。不得先报模型名。
3. **复演机制。** 选一个代表对象，从初始化到终端逐步复演；检查正常—异常—恢复、模式切换、生命周期、分母与暴露窗口，以及策略是否改变未来数据。
4. **攻击首次理解。** 至少构造一个替代解释、一个边界情形和一个致命反例；凡求最少先查0/1，凡求最优先查目标是否存在、唯一且有区分度，凡做反演先查可辨识性。
5. **裁决方法。** 给出最低可行基线、基线失败点、只为修复该失败而增加的结构、被拒路线及理由。输出必须包含变量、关系/递推、约束、算法入口与出口、验证和失败信号。
6. **冻结初稿。** 在检索同题论文或讲评前保存首次分析与题面哈希。若用户只要求思路，在母问题、信息边界、主路线和验证门均可核对时暂停确认；若用户已授权连续完成，则继续但保留冻结点。
7. **解锁对照。** 需要外部校准时按“原题/附件 → 命题人或官方讲评 → 评阅反馈 → 奖项核验论文 → 赛后研究”排序。分别比较题目理解和求解方法；论文只能补漏，不能因获奖身份覆盖题面事实。
8. **升级通用规则。** 只有跨两个不同结构问题成立、能描述触发条件、不会使旧题退化的机制才进入规则；单题技巧留在案例层。

## 当前默认输出

用户只要求思路时，输出到可核对节点即可：

- 题目真正要求什么，以及最容易误读什么；
- 每问交付物、信息时点和分问依赖；
- 一条主路线、一条条件升级路线、一条明确拒绝路线；
- 数学闭合接口：变量、关系、约束、求解出口；
- 最可能推翻方案的反例、验证门和需要用户确认的关键歧义。

表达不采用固定八股格式：机理题可以按状态演化讲，数据题可以按证据链讲，优化题可以按可行域与决策讲，构造题可以按下界—构造—证明讲。结构随赛题变化，但审计门不省略。
