# V27正式版：AI时代数学建模赛题理解与方法裁决器

状态：正式运行版。自2026-08-28起替代v26作为新题默认入口；v26保持原样作为回滚基线。

V27的用途不是记忆往年题答案，也不是收到题目后套往年模型。它先从新题原文、附件、图表和输出要求独立恢复问题结构，审计信息边界、可辨识性、最小性、事件与轨迹、实验单元、政策反馈和反事实口径，再选择可计算、可验证的方法。往年国一论文、专家讲评和赛后研究只在首次分析冻结后用于查漏与反证。

人工或Codex只需从 [从这里开始_给Codex.md](从这里开始_给Codex.md) 进入。

## 版本边界

- 深度训练定位：A、B、C题；D、E保留完整读题与约束闭环，但不扩充专用模型库。
- 当前可以完成：完整读题、歧义裁决、分问依赖、母问题提取、方法路线比较、数学闭合设计、验证与失败门、论文思路骨架。
- 当前不自动代表：已经得到数值解、已经完成代码复现、已经写完论文、保证获得某一奖项。
- 历史公开题的隔离测试不是未来保密题的统计证明；遇到真正新题仍需先冻结初次分析，并记录失败模式。
