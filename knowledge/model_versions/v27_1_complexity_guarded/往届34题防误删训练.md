# 往届34题防误删训练

## 训练目的与资料边界

本轮不重新学习题目答案，而是把V27.1的删减门逐题施加到既有、已经完成隔离分析与论文对照的材料上，检查是否会误删必要结构。覆盖：23道原训练题及其58篇论文记录、2018B先导题、5道留出题、5道2016—2017历史隔离题，共34题。

判定含义：

- **保留**：由题面、分问依赖、硬约束、结构不确定性或独立验证责任触发；
- **定向删减/降级**：只删无独立作用、无数据承载、比较不公平或证据等级不够的部分；
- **PASS**：删减后仍能生成全部题目交付物，且没有把真正需要的多阶段、多模型互证或复杂求解器删掉。

## 训练发现并写回的四项修正

1. **不按模型数量停止。** 34题中多阶段、多分问和多信息结构普遍存在；模型多可以是题目要求，只有边际作用为零才停止。
2. **统计承载不限制题面强制机理。** 样本量约束待拟合自由度，不删除由几何、守恒、动力学、事件或逻辑决定的状态。
3. **求解器复杂度单独判断。** 非凸、离散或连续事件问题可保留全局候选、局部精化和独立复算；它们必须使用同一评价器，并由可行性、目标值、下界或收敛证明价值。
4. **同输出不等于重复。** 若两条路线分别承担候选生成、下界证明、误差边界或独立复核，应同时保留；只在证明责任与结论贡献都重复时删减。

## 结果

34题全部通过“交付物完整性”和“必要复杂度保留”检查：34 PASS、0误删、0因固定数量限制失败。该结果是对既有赛题记录的规则回放，不是假装重新得到全部数值解，也不证明未来题绝不会出现新缺口。
