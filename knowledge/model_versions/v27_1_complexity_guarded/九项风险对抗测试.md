# V27.1九项风险对抗测试

测试目的：确认修复能阻止过度建模，同时不误删多阶段问题真正需要的组件。以下均是规则级反例，不是往年题答案训练。

| 风险输入 | V27.1必须作出的裁决 | 结果 |
|---|---|---|
| 同一交付物列出回归、随机森林、XGBoost、神经网络和集成，只因都能运行 | 不按数量机械删除；逐个检查角色和证据，没有不同结构假设、互证价值或独立收益的候选才删除 | PASS |
| 基准已满足题目与硬约束，复杂模型只提升一个未预先指定的次要分数 | 触发停止门1和3，保留简单模型 | PASS |
| 分析列出大量泄漏、边界和反例，却没有变量、方程、算法出口 | 状态只能是“审计完成”，禁止写成“已求解” | PASS |
| 题面没有行为响应、接触或因果信息，却主动加入相应机制 | 因缺少原始证据和可证实基准缺陷，不通过触发门 | PASS |
| 在同一验证集上试几十组模型和参数后汇报最高分 | 验证集已被选择污染；停止最优声明，要求嵌套验证或新独立证据 | PASS |
| 高级模型与一个故意不调参、缺关键合法特征或违反约束的基准比较 | 公平比较门失败；候选提升不成立 | PASS |
| 少量独立对象被拆成大量重复行，随后训练高容量模型 | 以独立对象计算有效样本；数据承载门失败，复杂路线降为诊断性 | PASS |
| 论文正文并列多条路线，读者无法判断哪条产生最终结论 | 标明路线的串联、分支、互证或淘汰关系；保留所有必要路线，只移除无作用重复项 | PASS |
| 观察数据回归显著，论文写某措施导致结果改善 | 因果门失败；降级为描述关联、预测结论或明确的模型情景 | PASS |

## 防止错误减模的反向测试

| 必要复杂结构 | 为什么不应被删除 | V27.1裁决 |
|---|---|---|
| 预测结果必须进入后续优化，二者分别产生不同交付物 | 属于必要串联组件，不是同功能模型堆叠 | 保留，并传播预测误差 |
| 几何标定后才能进行图像反演 | 两阶段具有不同状态和输出，省略标定会使反演不可辨识 | 保留 |
| 事件发生前后方程不同 | 单一平滑模型违反题面机制 | 由反例触发最小模式切换结构 |
| 基准违反硬约束，复杂路线首次获得可行解 | 改善的是可行性，不要求仅凭预测分数证明 | 保留并直接验证约束 |
| 多个模型分别代表题面无法预先排除的结构假设，结论在模型间不同 | 必须保留分支并用数据、边界或情景裁决，不能为了简洁强行只留一个 | 保留并报告结构不确定性 |

## 回归结论

九项用户指出的风险全部被明确阻断；五类真正必要的多阶段、互证或复杂结构仍可通过。V27.1限制的是无证据的候选竞争和无收益复杂度，不限制题目本身要求的数学深度，也不按模型数量机械删减。
