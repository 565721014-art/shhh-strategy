## 按结构而不是按背景取证

## 取证规则

1. 一个新题至少从两个背景不同的旧题取证。
2. 优先匹配“数据单位、状态变化、决策时点、约束和验证”，行业词只作最后参考。
3. 匹配结果必须写成“迁移什么、为什么能迁移、什么不能迁移”。
4. 若只找到一个旧题高度相似，必须再找一个共享局部组件的异背景题作为反例检查。
