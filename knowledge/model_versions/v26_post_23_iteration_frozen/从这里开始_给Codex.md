# 从这里开始：给 Codex 的新题入口

## 用途

当用户给出任何一份从未见过的数学建模赛题时，本文件是唯一需要人工指定的入口。Codex不得先搜索“最像的往年题”，也不得一次重读58篇论文。

## 最小读取链

按顺序读取：

1. [任意新题分析协议.md](任意新题分析协议.md)：建立新题事实、结构指纹和母模型；
2. [读题理解深度审计.md](读题理解深度审计.md)：用替代解释、对象生命周期、阶段边界、信息能力和目标代理反例验证是否真正读懂；
3. [置信度_冲突与缺失信息协议.md](置信度_冲突与缺失信息协议.md)：处理题意歧义、组件竞争和信息缺失；
4. [模型组件与国一经验库.md](模型组件与国一经验库.md)：只选择被新题事实触发的组件；
5. [国一经验迁移矩阵.md](国一经验迁移矩阵.md)：在独立路线形成后选择异背景证据；
6. [新题分析输出规范.md](新题分析输出规范.md)：生成分析结果。

只有当需要核对某个国一做法的公式、图、论证或失败风险时，才进入 [国一论文成品教材](../国一论文成品教材/README.md) 定点读取相应题目章节；不得为了分析一份新题重新通读58篇。

## 可直接执行的口令

> 完整读取我提供的新题正文、附件说明、数据字典、图表注释、输出模板和每一问。先建立事实与歧义，不引用往年题；再对代表对象做生命周期复演，检查替代解释、初始化—过渡—稳态—终端、正常—异常—恢复、信息能力阶梯、主目标与代理指标冲突，以及输出字段能否由模型生成。未通过理解证书前不得锁定唯一模型。通过后再生成八轴多标签结构指纹、各问依赖图和母模型；对候选组件给出支持、反证、缺失信息和置信度，随后形成基线、条件升级、验证与失败门。独立路线完成后，再用异背景案例检查迁移，并在存在同题高水平材料时用三份以上材料分别审计“读题理解”和“求解方法”。发现遗漏先升级通用机制，不记忆题目答案。

## 输入完整性门

开始分析前检查是否具备：

- 原题全部页面，而非题目摘要；
- 所有问题与小问；
- 附件名称、字段解释、单位和取值编码；
- 图片、示意图、公式、脚注和表注；
- 赛题另行规定的输出文件或精度要求。

缺少材料时仍可先做“暂定分析”，但必须把结论分为已确认、合理推断和待确认三类，不能把缺失部分默认为不存在。

## 完成判据

只有以下条件同时满足才算完成读题分析：

- 每一问均有明确交付物和信息时点；
- 会改变模型族的替代解释已裁决或保留分支；
- 代表对象生命周期和最小动作链可以按文字复演；
- 初始化、终端、异常和恢复阶段均已检查；
- 主目标未被未经证明的代理指标替代；
- 每个核心变量都有角色、单位、索引和来源；
- 至少提出一个可运行基线和一个有条件升级方案；
- 每个选中组件均有新题原文证据和反证检查；
- 硬约束、边界、误差和失败信号均可检查；
- 历史案例只用于校验，删去它们后，新题分析仍然成立。
