# 未见新题压力测试

以下题目不在23道历史题中，用于验证引擎能否组合经验，而不是背诵旧题。

## 压力测试一：城市共享电动自行车充换电与调度

### 假设新题

给出各站点小时级借还车、剩余电量、道路时间和电价，要求预测需求，确定车辆调度、充电站容量和实时再平衡策略，并考虑恶劣天气。

### 正确结构指纹

- 任务：预测 + 多期配置 + 网络路径 + 在线控制；
- 数据：站点面板/时间序列 + 道路网络；
- 演化：小时状态转移 + 事件触发重优化；
- 决策：车辆整数流、充电容量、路径和控制序列；
- 不确定性：需求、天气、行程时间；
- 目标：服务率、成本、电池风险多目标。

### 应组合的组件

特征—预测—决策闭环、多期状态转移、随机风险传播、网络传播与时变路径、多目标分层优化。

### 可调用但不能照搬的国一经验

- 从生产企业原材料的订购与运输迁移逐期库存和运输容量，不迁移原料换算系数；
- 从蔬菜类商品的自动定价与补货决策迁移需求预测进入决策，不迁移价格弹性形式；
- 从交通流量管控迁移时变道路状态与回溢，不迁移信号相位；
- 从农作物的种植策略迁移相关天气场景和风险指标，不迁移轮作约束。

### 若引擎错误会出现

只把它归类为“路径题”并求静态最短路，或只预测需求却没有车辆、电量和充电状态转移。

## 压力测试二：新型涂层光谱测厚与固化工艺优化

### 假设新题

给出不同入射角反射光谱、炉温和固化后厚度抽检，要求建立测厚模型、诊断多次反射影响、反演厚度并优化固化温度和时间。

### 正确结构指纹

- 任务：机理建立 + 信号处理 + 参数反演 + 实验响应 + 工艺优化；
- 数据：多角度光谱与实验组合；
- 不确定性：测量噪声、材料色散、工艺批次；
- 决策：温度和时间连续变量；
- 验证：多角一致性、抽检厚度、残差频谱和域内优化。

### 应组合的组件

机理正向、参数反演、信号预处理、实验响应与补充设计、风险传播。

### 可调用但不能照搬的国一经验

- 从碳化硅外延层厚度的确定迁移相位—厚度反演、多角共享参数和模型诊断，不迁移SiC色散方程；
- 从炉温曲线迁移固化热过程、参数校准和工艺约束，不迁移回焊温区阈值；
- 从乙醇偶合制备C4烯烃迁移因素交互、支持域内优化和确认实验，不迁移催化剂变量。

### 若引擎错误会出现

看到“光谱测厚”就直接复制SiC公式，或看到“工艺优化”就只用遗传算法而没有建立固化响应与验证实验。

## 压力测试三：校园传染病预警与干预资源配置

### 假设新题

给出学生每日症状、检测、宿舍接触、课程出勤和干预记录，要求预测暴发风险、确定预警阈值、分配检测资源并评价过去一次干预效果。

### 正确结构指纹

- 任务：重复测量关系 + 时序预警 + 不平衡分类 + 网络传播 + 资源决策 + 干预评价；
- 数据：学生纵向面板、接触网络和事件日志；
- 信息：检测有误差，潜伏状态部分可观测；
- 决策：阈值、检测配额和宿舍/人群优先级；
- 证据：预测与因果评价必须分开。

### 应组合的组件

纵向与首次事件、特征—预测—决策、网络传播、抽样信息价值、预测与因果分界、多目标风险分层。

### 可调用但不能照搬的国一经验

- 从NIPT的时点选择与胎儿异常判定迁移主体重复测量、首达风险和阈值校准，不迁移医学阈值；
- 从中小微企业的信贷决策迁移概率校准后再分配资源，不迁移企业特征；
- 从交通流量管控迁移网络状态和措施反事实评价，不迁移排队公式；
- 从生产过程中的决策问题迁移检测信息价值和误差传播，不迁移零件决策树。

### 若引擎错误会出现

把每天每名学生当独立样本、随机拆分训练测试，或用干预前后病例均值直接宣布因果有效。

## 测试结论标准

引擎只有同时满足以下条件才算通过：

1. 不依赖新题与旧题的行业名称相同；
2. 每题调用三个以上组件；
3. 每题从至少两个不同背景国一题取证；
4. 明确列出不能迁移的旧题专属条件；
5. 输出母模型、状态/信息时点、验证和失败信号；
6. 不用算法清单替代问题结构。
