# AI时代读题训练

本目录用于把现有 v26 从“国一论文经验归纳”升级为“AI时代新赛题的题意锁定、方法裁决与错误审计引擎”。

训练上限按以下顺序确定：

1. 组委会发布的命题人或赛题负责人讲评：校准题意、命题意图和常见错误。
2. 总体评阅报告与单题评阅综述：校准真实失分模式。
3. 可核验国一等奖论文：校准竞赛时间内的高水平落地能力。
4. 组委会赛题后续研究与命题组正式论文：寻找国一方案仍可改进之处。

旧年份国一只作为机制案例和回归测试，不再作为能力上限。

## 每题训练顺序

官方原题与附件完整读取 → v26 独立分析冻结 → 解锁官方讲评 → 解锁可核验国一 → 解锁后续研究 → 区分题意遗漏、方法差异与论文错误 → 仅把跨题通用规则加入候选 v27 → 全量回归。

## 读题输出锁

每题只要求锁定六项：母问题、信息边界、分问依赖、最小性/可辨识性、主方法裁决、致命反例与验证门；在六项未锁定前，不进入完整数值求解。

## 版权边界

官方讲评网页以图片形式发布且标注限制下载/转载，因此本地只保存来源索引、分析结论和可迁移规则，不复制讲评原图或整套讲评内容。
