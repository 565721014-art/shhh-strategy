# 国一论文成品教材

这是给 Codex 直接读取的成品知识，而不是让 Codex 再去搜索PDF的索引。

## 最快入口

- 只研究一道题：直接打开 `chapters/` 中以完整题名命名的章节。
- 跨题比较或一次性交给 Codex：打开 `总教材_23道完整题目_58篇国一经验.md`。
- 程序化选择章节：读取 `textbook_manifest.json`。

## Codex读取约定

1. 先按完整题名定位章节；不要只按题号回答。
2. 优先使用章节内已经消化的方案、国一共识与风险，不重新读取58篇PDF。
3. 只有精确核验公式、图形、表格或数值时，打开章节已经给出的具体原页PNG。
4. 原题文本、附件字段和全部论文逻辑已写入章节；原PDF和全文OCR仅作为底层证据。
5. 若要迁移或备份，请整体复制 `knowledge/` 目录；成品教材中的视觉证据和原附件使用该目录内的相对链接。
