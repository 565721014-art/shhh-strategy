# 读题理解深度审计

## 一、为什么原有事实清单仍可能低于国一水平

事实表、变量表、信息时点表“存在”，不等于题目已经被深入理解。原引擎容易出现九种机制性失误：

1. **覆盖代替理解**：只检查某个栏目是否写过，没有检查它能否排除错误解释。
2. **过早统一抽象**：太早寻找母模型，把只在启动、异常、终端或某类对象上出现的不对称细节抹平。
3. **歧义没有向后传播**：列出“可能有歧义”后仍只沿一个分支建模，没有检查另一解释会怎样改变变量、约束、目标和结果文件。
4. **只看稳态主体**：忽略初始化、状态切换、边界时刻、未完成动作和终端计数。
5. **信息权限被压成已知/未知二分**：没有区分当前已观察、可由确定规律推算、只能收到事件信号、未来随机且不可预知等层级。
6. **主目标被代理指标偷换**：为了方便求解，用等待时间、利用率、误差或距离等替代真正交付目标，却没有构造两者冲突的反例。
7. **文字模型无法操作复现**：变量与公式看似齐全，但无法逐步演示一个对象从进入系统到形成最终输出的完整生命周期。
8. **历史校验只证明相似，不主动找遗漏**：异背景案例能防照搬，却不能替代同题多篇高水平方案对题意分歧的集中暴露。
9. **完成判据偏确认性**：检查“我是否写到了”，而不是主动寻找“什么证据能证明我的理解错了”。

因此，读题阶段必须从“覆盖检查”升级为“反事实、生命周期和可复现性审计”。本文件是进入结构指纹和求解方法前的硬门。

## 二、审计原则

### 1. 理解与求解必须分层

- 理解层只回答：对象是什么、何时变化、能知道什么、必须交付什么、怎样才算合法。
- 求解层才回答：选什么模型、算法、搜索深度、参数和求解器。

若一句判断必须依赖某个算法才显得成立，它通常还不是稳定的题意理解。

### 2. 先保留题目特异性，再寻找母模型

先完成对象生命周期、阶段差异和异常分支，再抽象共同状态。母模型必须能够还原题目中的特殊动作；不能用“统一”作为删去特殊语义的理由。

### 3. 每个关键判断都要能被反驳

除支持证据外，还要回答：

- 哪个原文、附件结构或手算事件会推翻它？
- 如果采用另一种解释，最先改变的变量、约束和输出是什么？
- 两种解释是否会改变模型族或仅改变参数？

## 三、九步强制审计

### R1：逐句作用域复核

对定义、动词、量词、否定、例外、时间词和指代逐句复核，特别检查：

- “每个、任意、至少、仅、依次、同时、首次、实时、完成、有效”等词的作用对象；
- 限制是针对整个周期、某个动作、某类对象，还是某一小问；
- 括号、表注、脚注、图例和附件字段是否改变正文含义；
- 同一术语在不同小问是否换了角色或统计口径。

产物不是抄题，而是“原句—解释—影响对象—证据状态”。

### R2：替代解释树

对每个会改变模型的弱推断，至少保留A/B两个解释，并向后传播：

| 项目 | 解释A | 解释B | 会改变什么 | 用什么裁决 |
|---|---|---|---|---|
| 对象/动作含义 |  |  | 状态、变量或约束 | 原文、附件、数据或用户确认 |
| 时间与边界 |  |  | 计数、可行域或事件顺序 | 表注、结果模板或手算 |
| 信息权限 |  |  | 离线/在线模型 | 决策时点与可观测字段 |

不得只写“存在歧义”然后继续使用未标注的唯一分支。

### R3：代表对象生命周期

选择一个最小代表对象，从进入系统到最终交付逐步追踪：

`来源 → 状态变化 → 被哪个资源占用 → 决策发生 → 中间产物 → 异常分支 → 最终计数或退出`

每一步记录：开始条件、结束条件、耗时/单位、信息可得性、资源互斥和身份是否守恒。若无法完整走通一个对象，母模型尚未闭合。

#### R3.1：给定量去向审计

为正文、图、表和附件中每个显式给出的非平凡量标记唯一或多个去向：状态、决策、待估参数、硬约束、验证基准、输出字段，或“经证明与本问无关”。尤其检查几何尺寸、采样间隔、编号、单位、精度和阈值是否会改变模型族。若一个降阶模型丢弃了题目刻意给出的量，必须用量纲数、嵌套模型比较、残差结构或误差上界证明该简化合法；“为了方便”不是证明。

这项审计只确定最低机理保真度，不强迫使用最复杂模型。复杂模型若引入不可辨识参数，仍应退回可验证的较简模型或保留两级路线。

#### R3.2：过程时钟与记录时钟对齐

动态数据必须分别定义：系统过程起点、传感器开始记录时刻、附件时间戳零点、决策时点、事件触发时刻和结果文件要求的时间基准。附件第一行只能说明“第一条可见记录”，不能默认等于系统初态；存在阈值触发、延迟启动、截断观测或跨设备时钟时，必须写出时间变换并检查其可辨识性。

#### R3.3：语义字段与暴露量审计

名称、备注、状态、编码、单位和表头即使看似标识符，也要检查是否含对象类型、组织关系、行业词、事件状态或测量口径。只能提取文本实际支持的语义，并标记为可确认、模糊或未知；不能整列丢弃，也不能从遮蔽字符和编号强猜类别。

对金额、次数、事件率和变化率，同时记录其暴露分母：活跃时长、完整观测天数、人口/面积、交易机会或检测次数。不同入组时长、右截断周期、节假日和缺测窗口未对齐前，不得直接比较总量或同比。

#### R3.4：定义外推与局部—整体审计

当一个定义、比例或公式从平面、等宽、独立、稳态等原适用域推广到斜面、变宽、相关、动态或分区情形时，不能只做符号替换。先回到它所描述的物理集合或统计事件，明确分子、分母、基准测度和方向；至少构造两个候选定义，并用退化情形、极端构型、微型数值仿真或几何草图裁决。若题面无法唯一裁决，则保留口径分支并报告敏感性。

同时检查局部最优是否真的能推出整体最优。局部宽度、局部损失、单段效率或单区可行性必须与全局分母、边界截断、连接成本、分区接缝及未覆盖孔洞一起评价。分区求解后必须单独审计跨区接缝；使用插值器或代理模型参与优化时，还要验证约束附近的函数值、梯度/几何事件，并把最终方案送回高保真正向模型复算，防止优化器利用代理误差。

#### R3.5：历史决策生成机制、结构零与周期审计

历史输出往往是在旧策略、旧订单、旧调度或旧筛选机制下才被观察到。对“请求/分配/检测/曝光 → 响应”的数据，必须区分主动决策、潜在能力和实现结果：没有下单时看不到供应能力，没有派车时看不到运输损耗，没有检测时看不到真实状态。观察到的最大值通常只是潜在能力的下界，历史总量和频次也可能主要反映过去的选择偏好；未经条件响应建模和支持域检查，不得把它们直接当作对象固有能力。

每个零值都要在真实零、未发生动作、未暴露、缺失、删失和低于检测限之间分类，并让分母只包含真正处于风险或被观测的机会。若数据生成机制无法识别，保留分支或使用选择模型/部分识别，不能用统一补零解决。

计划窗口、附件长度、生产年度和自然周期是四个不同概念。周期候选应来自日历、机理和数据谱/相关结构，并与非周期、趋势及其他合理周期在滚动时间外验证中比较；不得因为要规划24期，就把历史机械切成24期周期。存在历史决策周期时，还要说明观察到的是外生季节性还是旧策略重复造成的内生周期。

#### R3.6：实验单元、测量单元与伪重复审计

先找出干预真正被独立分配的最小单位，再区分在同一单位上的重复测量、技术复测、相邻时点、多个响应分量和数据处理后生成的行。样本量、误差自由度、训练验证划分和因果措辞都必须以实验单元为基础；同一对象的相邻温度、同一人的多帧、同一样品的多条谱线不能因为占多行就被当作独立样本。

插值、样条补点、均值填充、数据增强和模型预测只增加计算表示，不会创造新的随机化、独立重复或误差信息。不得用补出的点填满正交表后执行方差分析，也不得把同一实验单元的原始行与生成行拆入训练和验证。运行顺序、批次、累计使用时长、预处理时长和仪器漂移若与处理水平同向变化，必须作为混杂候选；无法由现有数据分离时，结论降为条件关联，并在补充实验中用随机化、区组或交叉设计裁决。

#### R3.7：严格边界、联合支持域与可取得最优审计

逐字区分 `<`、`≤`、开区间、闭区间、离散档位、设备分辨率和安全裕量。连续开域上的目标可能只有上确界而没有可取得的最大值；此时不能把边界点当作答案，应报告上确界性质，并用题面允许的档位、测量精度或明确声明的安全间隔转成可执行方案。边界取值还要核对小问作用域，不能用“接近”偷换严格限制。

多因素优化的合法域是历史联合设计、物理恒等式和工艺约束共同形成的集合，不是把各列最小值和最大值拼成一个矩形。组成比例与总量、派生量与原变量、类别与可用水平之间若存在确定关系，优化器必须在原始可实现参数化或联合支持邻域中搜索。候选点应同时报告到最近实验单元、联合凸包或密度支持的距离；落在稀疏边界或域外的点只能作为待验证假设，不能与域内最优同等确定地交付。

#### R3.8：标签、参照标准与任务层级审计

题目同时给出检测判定、代理标签、专家结论、后续真实结果或不同时间尺度结局时，先逐项写清：题面要求预测哪个标签、标签在哪个对象和时点产生、谁制定、是否可能受输入规则直接决定、是否存在更晚但不同任务的参照标准。不得因某列看起来“更真实”就替换题目指定标签，也不得用未来结局训练当时不可获得的判定任务。

若特征本身参与生成标签（例如规则分数与由该分数形成的判定），高准确率首先说明模型复现了操作规则，不自动证明发现了独立机制或临床有效性。应分开报告规则复现、复杂模型增益、与外部参照标准的一致性；标签从记录级提升到主体级时，还要定义多次记录如何聚合以及冲突如何裁决。

#### R3.9：风险偏好、序数代价与唯一最优可识别性

“低/高/极高”“尽早”“兼顾准确”等只提供顺序或方向，不自动给出可相加的数值代价。先识别题面是否给出权重、容忍概率、预算、阈值或临床最低保证；若仅有序数偏好，不能任意指定指数、倍数或线性权重后宣称唯一最优。应给出Pareto前沿、保证水平下最早可行方案、权重区间内稳健方案，或明确把权重作为需要用户/专家确认的政策参数，并报告切换点。

动态首次事件还要把潜在事件过程与观察过程分开：首条阳性只把真实事件定位在相邻观察之间，首测阳性与始终阴性分别产生左/右删失；检测失败和复检时点可能具有信息性。技术复测可估计测量误差，但不能缩窄生物事件区间或充当新的主体轨迹点。

#### R3.10：移动对象、固定工位与材料坐标审计

对象在空间中移动而传感器、加工点或边界固定时，至少分开三种坐标：全局空间位置、随对象移动的材料/身份坐标、设备工作坐标。事件在上游时刻发生，不等于该段对象当时已到下游设备；必须用速度、距离和设备运动状态传播到可操作时刻。设备若随对象同步运动，还要区分动作启动位置、动作完成位置、加工线在材料坐标中的位置和设备返回后的下一可用时刻。

验证必须在统一事件仿真器中同时守恒对象身份、材料长度/质量、时间和资源互斥。只按时间间隔切段或只按空间长度排样，若不能还原每个动作实际发生在哪个对象位置，均不能证明方案可执行。

#### R3.11：在线计划版本、承诺边界与追溯重排审计

在线方案要保存每次事件前的实际计划版本、已经完成的动作、正在执行且不可撤销的动作、尚可调整的动作和当时已知信息。新事件只能从当前真实状态向前重排，不能把调整后方案与一个从未发布、使用未来异常或假设历史无异常的反事实计划混作“初始方案”。若题面未授权中止或回滚，已启动动作必须冻结；若允许取消，要显式计入取消时间、损失和资源恢复。

每次调整输出事件日志：触发事件、旧版本、冻结前缀、变更后缀、调整原因、目标改变量和不可调整原因。离线知道完整事件序列只能用于回放评价，不能进入在线策略的当时决策。

#### R3.12：优化不变常数与交付口径恢复审计

某些不可避免的损失、固定成本或已发生沉没量对所有候选相同，优化时可从目标中删除以简化求解；但这只保持方案排序，不改变题目要求的绝对统计口径。最终表格必须恢复这些常数，并同时报告“可优化增量”和“总实际量”，说明基准区间与是否重复计入。不得因为常数不影响最优解就从交付结果中消失。

#### R3.13：索引、行序与过程顺序合法性审计

编号、Excel行序、文件名、采样点标签和附录排列只有在题面明确给出时间、空间、阶段或生成顺序含义时，才能作为序列坐标。相关编号可能只是标识符，排序后做时间序列、趋势外推、滞后相关或状态转移会制造不存在的过程。先寻找真实时间戳、空间坐标、同一对象的有序重复或工艺批次；没有则按横截面/分层样本处理。

若文本标签中含“部位、未处理点、严重状态”等语义，应解析为采样层级或状态，而不是从数字前后强猜顺序。任何序列模型都必须写出相邻两行之间真实发生了什么，并用打乱行序测试：若随机重排不应改变科学结论而模型却改变，序列假设不合法。

#### R3.14：边界假设、无差异区与有限样本可判定性

当任务要区分参数“超过阈值”和“不超过阈值”，而两侧在阈值处无间隔时，任何有限样本检验都无法对任意接近阈值的两种参数同时保证高把握度和很少样本。必须明确原假设/备择、拒绝/接受方向、两类错误分别由谁承担，并选择：业务上最小有意义差异形成无差异区、序贯检验允许继续抽样、设最大样本后输出无结论，或给一侧置信序列而不承诺必停。

比例数据服从二项/超几何抽样结构；不能因为总体方差未知就机械改用连续正态均值的t检验。正态近似只在尾部样本量条件满足时作近似，并必须用精确二项枚举校验实际错误率、整数边界和期望样本量。

#### R3.15：循环回收、条件质量信念与吸收性审计

拆解、返工、退货、重试或恢复把对象送回上游时，流程图含有返向边，不能只算一轮成本。状态至少记录对象来源、已发生检测、已观察失败、质量后验和剩余可用资源；失败后回收对象的质量分布通常不同于新对象先验。若把已检合格与未知质量对象混池，还要追踪混合比例或保持分仓。

固定策略必须证明过程以概率1到达出售、报废或其他终止状态，且期望访问次数、成本和时间有限。用吸收Markov链、Bellman方程、更新方程或多轮仿真累计全部循环；对无吸收或无限期望成本的策略直接判不可行，而不是由有限仿真截断伪装成盈利。

#### R3.16：时空场事件、边内状态与全程可行性审计

网络中的节点首达、边前锋通过、局部状态跨阈值、整边充满/失效是不同事件。节点时间只能说明某一位置的首次事件，不能替代边内部随位置和时间变化的状态函数。若行动耗时，边在出发时可行不代表穿越期间一直可行；转移代价应由沿轨迹积分或事件求根得到，并检查等待是否可能改善/恶化可达性以及时变最短路的FIFO条件。

路径验证必须将最终轨迹送回原时空场，连续检查每一点的状态、方向依赖速度和阈值。按端点最早事件给整条边固定权重、只检查到达节点或在边界跨越后仍允许完成穿越，均需题面授权，否则不能作为安全证书。

#### R3.17：多源共享状态、汇流耦合与守恒叠加审计

多个源进入同一系统时，它们通常共享容量、队列、库存、压力或风险状态。分别求单源结果后取最早、相加概率、把时间简单除以源数，只在已证明线性且互不改变边界条件时成立。汇流会改变下游流量和蓄积速度，两个前锋相遇也不会自动让所有尚未到达区域的时间等比例缩短。

主模型应在同一状态空间中按各源启动时刻注入并联合推进，保持总输入、内部储存、输出和损失守恒；单源叠加只作可验证的加速近似，并在汇合、饱和、阈值和容量活跃处与联合模型对照。

#### R3.18：测量轴、预处理算子与验证作用域审计

连续光谱、轨迹、波形和图像特征首先是同一对象上的有序测量轴，不是新增独立样本。先核对轴方向、单位、重复坐标、不同设备/模态的覆盖区间，以及题面明确允许的校正负值、检测下限和饱和值；不能把合法的仪器校正值按常识截零、取对数或删作异常。平滑、基线校正、SNV/MSC、导数、插值、峰提取、波段筛选、PCA/PLS和缩放只要会从多个对象学习参数，就必须在每个训练折内重拟合。

验证应按真实独立对象、主体或样品分组，把同一样品的重复谱、相邻帧和增强副本留在同一折。连续轴上的单点重要性必须通过相邻波段成组、轴轻微平移、基线漂移和噪声扰动检验；降维图分离、全数据预处理后的交叉验证和随机拆分高分都不能单独证明部署泛化。

#### R3.19：部分标签、多任务层级与预测标签回灌审计

同一对象有多个标签时，分别列出全标签、仅标签A、仅标签B、全缺失四种观测模式；“缺一个标签”不等于该对象对另一任务无监督价值。先判断标签是并列、多任务还是层级条件关系，并核对相同编码在不同上层类别中是否共享语义。若先预测上层标签再用于下层任务，必须在验证中用折外预测标签，报告上游错误传播；使用真实辅助标签得到的性能只代表该标签部署时确实可得的场景。

预测标签、自训练和双向回灌不能把本对象的真标签或全数据模型结果泄漏回自身。接受伪标签应有置信门槛、迭代停止和不使用伪标签的消融；最终同时报告各任务性能、联合正确率、层级一致率和双缺失对象不确定性。若标签映射本身缺失，无监督簇只能用中性编号，不能任意命名成真实类别。

#### R3.20：扩展源—有限目标—全遮蔽物的几何传递审计

当源具有角宽、空间范围或随机散布，目标具有有限面积/体积时，“中心射线瞄准目标中心”只确定姿态，不等于全部能量、概率或对象被目标接收。必须从源分布和发射面联合采样或积分，沿真实传播方向与有限目标求交；截断/命中分母要与此前遮挡、损失口径一致，不能重复扣减。除同类对象互相遮挡外，塔体、支架、边界、固定设施和目标自身也要进入候选遮蔽物清单，无法由题内几何确定的尺寸应显式参数化而非默认为零。

解析微例、空间相交可视化和采样加密应共同验证有限目标效率。用目标中心距离、中心点命中或无限平面投影替代有限体相交，只能作为经误差界验证的代理。

#### R3.21：方向性外力、采样设计与对称性破缺审计

可行域、边界或初始布局对称，不代表最优决策必须对称。太阳、风、流向、交通需求、单侧入口、时段采样和非均匀权重都可能破坏目标函数的旋转/镜像不变性。强制中心位置、同心同规格或对称分区之前，必须逐项证明外生输入及评价时点也在相同变换下不变；否则对称布局只作降维基线，并保留平移、偏心、非对称密度或规格的候选。

若评价来自随机射线、蒙特卡洛或抽样仿真，候选比较应使用共同随机数或固定样本、报告标准误和重复排序稳定性；优化器不能把采样噪声当作真实的不对称增益。

#### R3.22：潜在需求、暴露可得性与交易删失审计

交易销量通常是潜在需求经过是否供应/上架、陈列、价格、库存和售罄时点筛选后的实现量。没有交易记录不能自动填成零需求，售出量也不能在未知库存下当作完整需求；退货、取消、折扣清仓和跨日冲销应先按业务生命周期净额或分过程记录。先画“可供—上架—有库存—发生需求—成交—退货/损耗”观测链，只有暴露机会明确的零才进入零需求模型。

当库存和上架记录缺失时，需求只能部分识别：分别报告把销量当下界、把活跃窗口内无交易当零和假设无缺货三种情景，限制结论强度。品类汇总可以减弱单品可得性噪声，但仍不能消除售罄截断。

#### R3.23：历史行动内生性、价格支持域与先决—追索审计

历史价格、配额、陈列和补货是旧策略根据成本、季节、质量与预期需求选择的行动，行动—结果相关不等于因果响应。用于新策略时，应控制共同状态、利用自然/随机实验或给出未观测混杂敏感性，并把候选限制在有历史支持的行动域；优化器将预测模型推到未见价格、剂量或资源水平时必须停止并请求实验或保守外推。

按真实信息顺序区分先决变量、随机实现与追索策略：若补货时尚不知道准确成本/供应，而定价在到货后可调整，模型应先决定补货，再在成本情景下调用预先定义的定价规则。把未来成本、需求或可售品种作为确定已知量同时优化，属于完美信息泄漏。预测误差、损耗与退货必须进入最终利润/服务回测，而不是只优化点预测。

#### R3.24：路径约束刚性链、弦长递推与分支连续性审计

相邻铰点都位于同一曲线，不代表刚性连杆沿曲线弧段弯曲；约束通常是两点欧氏弦长固定，而实体总长还可能在铰点外继续延伸。应统一用有向弧长参数描述直线、曲线和分段路径，对每个后继/前驱点求固定弦长根，并用路径次序、上一时刻根和对象身份维持分支连续，防止在自交或多圈路径上跳到另一根。

速度由固定距离约束微分得到，必须检查连杆方向与路径切向投影分母接近零的运动学奇异。把弧长间隔当杆长、所有点设同速、在分段连接处重新编号，都会破坏刚性链生命周期。

#### R3.25：完整实体碰撞、保守剪枝与连续临界审计

有宽度的线段、矩形或多边形碰撞不能只检查中心点、顶点是否落入对方或到无限延长线的距离；边—边交叉、端部擦碰和有限线段投影都必须覆盖。凸多边形使用分离轴/精确距离，复杂实体可用保守包围体筛选后做完整窄相检测。相邻铰接实体的允许重叠与非邻接碰撞要按结构明示。

以“最可能先碰的局部对象”缩小范围必须有对全体对象保守的几何证明；否则只能加速候选排序，最终仍需全局验证。首次接触和全程最大速度/应力是连续事件或极值：离散帧只负责括区间，之后求根或自适应极值，并报告临界两侧证书。

#### R3.26：约束秩、真实自由度与目标不变量审计

看到“可调整”“优化”不等于目标仍有自由变化。先用等式约束消元、自由度计数和退化构型检查目标是否已被几何/守恒关系固定；若目标在全部可行解上恒定，应给出不变量证明并停止虚假寻优。只有放松了哪条原约束、增加了哪个新自由度后，才能讨论更短/更优，并必须说明那已是扩展问题。

数值优化器在常值或近常值目标上返回某个参数，只说明初始化、容差或噪声选择了代表点，不能声称该点优于其他可行解。

#### R3.27：可分资源的覆盖量词与弱出现约束审计

题目说“每个单元的所有资源在一个窗口内至少接受一次动作”时，不能只用二元变量表示动作曾出现；若资源可分，一小份正量就会让出现变量为1，却没有覆盖其余资源。先识别量词作用于“单元”还是“单元内全部资源”，再用累计处理量、可追踪子资源流或覆盖测度表达。出现型弱口径只能作为有明确文字支持的对照分支。

最小动作量与覆盖量是两件事：前者防止碎片化，后者保证整个资源经历过程。滑动窗口还必须把历史初态和跨窗口边界纳入，逐窗口枚举验证，不能只按不相交三年块检查。

#### R3.28：内生/模拟输出相关性与结构关系识别审计

优化得到的分配、模拟生成的一条路径或旧策略下的实现输出，是模型和行动的内生结果；其相关系数不能反过来当作现实中的替代、互补、因果响应或物理耦合。先说明关系来自机制、外部数据、实验识别还是纯情景假设。只有最后一种证据时，必须给符号、强度区间、联合支持域和敏感性，不能写成估计事实。

联合模拟需要保持题给边际趋势，相关矩阵须合法/正定，需求关系应作用于可解释的结构量（如交叉价格弹性），而不是把相关系数任意乘入价格、成本或决策变量。比较独立与相关情景时使用同一边际样本，避免把边际变化误当相关结构贡献。

#### R3.29：多阶段情景的信息集、非预见性与共同情景复评

先画决策—观测时间线，标出每个阶段可获得的信息。多个未来情景中，在分岔前作出的决策必须相同；先在每个完整未来路径上分别求最优再择优，只得到完美信息上界，不是可执行计划。若允许观察后调整，应把追索规则、冻结前缀和允许改变的变量显式写出。

候选策略比较必须在同一组情景或共同随机数下复评，并用独立高精度样本做最终确认。期望、最坏情景与CVaR回答不同偏好，不应以任意权重制造唯一方案；同时报告信息价值、尾部稳定性和情景数收敛。

#### R3.30：不等间隔率—总量积分与观测强度审计

流量、功率、瞬时排放率或风险强度是“每单位时间”的率，总量应为对真实时间的积分，而不是观测均值乘记录条数、把每行等权或先粗暴补成固定频率。相邻时点采用何种保持/插值、年界如何闭合、长缺口如何处理都要显式；复合率如流量×浓度还要传播两个因子的同步与缺测误差。

观测时钟不等于过程时钟。若高风险阶段加密采样、不同年份制度变化或某变量比其他变量稀疏，行级均值、变点和周期都可能反映观测强度。保留采样间隔与被测指示，做时间加权、强度敏感性和固定制度子集复算；未测值不能填零或用全局均值消去峰值。

#### R3.31：监测时点的信息价值、可用触发与遮罩回放审计

“变量预计较大”不等于“该时点最有监测价值”。采样目标应连接到下游任务，如全程重建误差、积分误差、峰值捕获、突变检测延迟、参数后验方差或决策损失；只要求所选值均值高、只采预测峰值或只让样本数最少，通常不能保证及时掌握动态。

静态日历只能使用设计时信息；自适应方案可依赖采样时已获得的廉价信号与历史样本，但不能依赖尚未发生的真值。不同传感器/检验的成本和信息量应分层。验证时在完整历史上按伪未来逐步遮掉未选观测，严格按规则决定下一次采样，再比较成本—误差—延迟Pareto，而不是先看完整曲线后挑点。

#### R3.32：季节共因干预、处理后历史与无处理反事实审计

干预固定发生在洪季、促销季、检修期或其他自然变化窗口时，简单前后差把季节共因、回归均值和干预效应混在一起。先定义处理效应对象、窗口、对照/匹配过程与前趋势，控制同期外部冲击；没有未处理单元或足够重复时，只能给敏感性范围，不能靠复杂预测器制造因果识别。

历史全部处于处理政策下时，直接外推历史趋势得到的仍是“持续处理”预测，不是“取消处理”反事实。无处理未来需要估计并移除处理贡献、建立机制情景或引入外部对照。若空间剖面/测量支持域随期改变，还须先固定共同坐标与结果定义，否则所谓处理前后差可能只是测量范围变化。

#### R3.33：早触发吸收事件与预定终点机制并集审计

对象沿路径运行时，接触、阈值、故障或告警可能在预定终点/定时动作之前触发并终止原过程。应先按时间顺序判断早触发；只有未触发分支才到预定状态执行后续机制。最终成功事件是各互斥分支或几何集合的并集，不能同时计算早触发和终点结果后重复相加。

可用统一状态事件函数复演：记录首次触发时刻、触发后的吸收状态，以及未触发时的终点状态。边界概率为零不代表实现可忽略优先级；离散仿真仍须避免同一对象在两个机制中重复计数。

#### R3.34：共享潜变量下多动作至少一次成功的联合覆盖审计

多个传感器、药剂、拦截器、检测规则或投放点若面对同一个未知对象/环境状态，其成功事件通常通过共享潜变量相关。至少一次成功应计算条件于潜状态的集合并集、包含排除或联合仿真，不能仅凭单次边际概率套用1−(1−p)^n。

只有给定潜状态后独立且随机机制确实分离时才可条件乘积；几何命中区互不相交时事件是互斥而非独立，此时并集概率等于概率和。强制不重叠可作可解释基线，但若题目允许重叠，就不能用它缩小全局优化域。验证必须覆盖完全重合、完全分离和部分重叠三种退化构型。

#### R3.35：观测事件、目标状态与轨迹转移语义审计

传感器记录的地点、到达方向、时间戳、编号或状态码，只能直接支持其字面观测事件；它不自动等于穿过节点后的转向、停留原因、排队等待、服务完成或某种行为意图。先画“潜在状态—产生动作—传感器触发—字段编码”的观测链，并以附件字典和一个可手算轨迹复核编码方向。需要由前后记录推断转移时，必须同时满足同一对象、时间顺序、拓扑可达、耗时合理，并把漏检、源汇、停车/离网和公共占位编号写入缺失机制。

同一对象再次出现在同一传感器，既可能是回环，也可能是长时离开后返回，不能直接当作该处连续等待；一个上游方向计数也不能由优化器凭空拆成未观测的多个去向。证据不足时输出转移概率、区间或可识别子集，并报告未匹配率对结果的选择偏差，而不是给伪精确标签。

#### R3.36：容量需求的存量—到达—服务—并发与服务标准审计

“一段时间内需要资源的对象总数”是流量，“同时被占用的资源数”是存量，二者不能直接互换。床位、停车位、充电桩、客服席位、库存货位等容量问题，应至少写出到达、进入服务、服务时长、离开/放弃和排队的状态更新；容量由峰值或风险分位的并发占用、等待概率、服务水平或尾部等待决定，而不是用总人数除以总时长得到的平均周转数。

只有到达平稳、服务时长已识别、资源持续满负荷且调度无空闲损失时，简单周转公式才可作基线。若现有容量、服务时长或“满足需求”的标准未给，绝对新增量通常只能部分识别：分别报告所需总容量、现有容量假设、新增量区间和服务水平敏感性，并检查服务时长变长或目标更严格时容量单调不减。

#### R3.37：控制动作进入状态转移与目标响应的闭环审计

使用强化学习、遗传算法或任意优化器前，先验证控制变量确实通过可解释的正向机制改变下一状态和主目标。若状态转移只按固定衰减加噪声，奖励只依赖当前外生状态，动作没有进入转移/奖励，任何“最优策略”都只是网络初始化、随机数或编号的产物；若用预设公式直接把某控制写成速度、收益或风险，也要证明该响应关系来自机理、标定或实验，而不是为优化而定义。

建立最小可运行模拟器，用相同需求/扰动对基线和候选做配对反事实复演，检查零动作、极端动作、动作交换和容量边界。优化器不能创造题目未提供的转向、信号响应、需求弹性或因果效应；响应不可识别时，给情景前沿、稳健界或补充实验，而非借高级算法制造数值答案。

#### R3.38：内生启停干预、实际暴露与网络溢出的反事实审计

当措施“根据实际状态临时启用”、高风险时才处理或执行强度未记录时，处理分配与潜在结果内生相关。先区分政策宣布区间、意向处理、实际启停时刻、强度和对象/空间暴露；只有政策包日期而无执行日志时，最多识别意向处理或情景效应，不能把逐时差值写成实际动作因果效应。

前后比较必须对齐日历、需求、季节、观测覆盖和共同趋势，并检查空间/网络干扰：处理区流量下降可能是需求减少、入口截流或向邻区转移。使用事件研究、差分、合成对照或机制仿真时，都应同时报告处理区、邻接区和系统边界的吞吐、等待与总量，执行前趋势、安慰剂和对照组敏感性；局部改善只有在全局口径未恶化时才能称为系统改善。

#### R3.39：图示坐标约定、旋向与手性审计

方位角、俯仰角、航向、顺逆时针、图像行列和局部轴的正向必须从题面图示、文字定义和至少一个特殊角共同恢复，不能默认采用数学教科书中的球坐标或右手旋转约定。先写“原坐标—角度零线—正向旋转—目标单位向量—逆变换”的闭环；用零角、直角和题图所在象限核对每个分量的符号，再把一个点正变换后逆变换，检查是否回到原点。

若两个约定只差镜像或轴交换，标量距离与目标值可能完全相同，优化器仍会给出看似合理的答案，但空间位置、方向和交付坐标会整体错误。凡结果含三维坐标、轨迹、姿态、反射方向或地图落点，都必须做象限/手性单元测试；题图分辨率不足时保留两种坐标分支，直到用附件或可核验结果裁决。

#### R3.40：设计目标态、约束实现态与真实性能态分层审计

“理想曲面/轨迹/配方/计划”“设备或网络实际能达到的状态”“由实际状态产生的最终性能”是三个对象。设计态定义追求方向，实现态受行程、连接、守恒、离散化和边界约束，性能态必须把实现后的真实变量代回正向模型；不能让离散节点被假定精确落在理想面后继续用理想法向验收，也不能只证明代理误差小就宣布主目标最优。

推荐采用外层设计参数—内层可实现状态—高保真性能评价的嵌套闭环，并分别报告设计误差、约束裕度和主目标。若理想态不可实现，应明确输出最接近的可行态及性能损失；基线与候选必须使用同一评价器、边界、分母和数值精度，否则所谓提升可能只来自验收口径变化。

#### R3.41：均值信息、非线性期望与场景概率质量审计

题目只给均值、成功率或死亡率时，通常只识别一阶矩；若下游含取整、阈值、最大值、短缺正部、排队或联合尾部，期望损失不由一阶矩唯一决定。不得把“平均每次2.2个”直接当作每次都产生2.2个，也不得擅自选Poisson、正态或二项分布后把结果称为题面唯一答案。应先做分布充分性审计：列出目标依赖的矩/相关/尾部，必要时给透明情景、矩约束分布鲁棒界或补充数据需求。

场景生成和压缩必须守恒概率质量，并保留对决策重要的尾部与状态关联。合并日期区间、聚类场景或删除低概率端点后，要重新校准权重并检查均值、方差、约束违约率和目标期望；所有期望应在非线性损失外层计算，即E[L(X)]，不能用L(E[X])替代。候选策略须用共同样本和独立样本外场景复评。

#### R3.42：整数容器、兼容合并与容量碎片审计

床位、车厢、机台、羊栏、托盘或批次等容量若以整数容器提供，所需数量不仅由总对象数决定，还受类型隔离、日期/温度/目的地兼容、同组跨度和容器容量影响。先定义哪些对象能共享一个容器，再做分组装箱；对每批分别向上取整会高估可合并对象的需求，把全体总数一次取整又会低估隔离与碎片，两者都不能未经证明作为真实容量。

平均对象日除以容量只能给乐观下界，不能证明逐时可行。最终计划必须逐时输出整数容器分配，核对跨阶段并发、组内兼容和边界回流；应同时报告理论满载下界、可行装箱需求及碎片率，并用单批、恰满、差一个对象和兼容窗口边界等微例验证取整方向。

#### R3.43：嵌套量词、集合协同与覆盖口径审计

多资源覆盖扩展对象时，量词顺序决定模型：`对每个目标点都存在一个资源覆盖`（∀q∃k）允许多资源拼接覆盖，强于只检查总面积却弱于`存在一个资源覆盖全部目标点`（∃k∀q）。同理，“每个目标至少一次”“所有目标同时”“任一目标被覆盖”和“各目标覆盖时长之和”分别对应不同的并交集与时间量词，不能用自然语言中的“全部、任意、分别、同时”相互替换。

先把对象维、资源维、时间维和情景维的∀/∃顺序写成逻辑式，再转成集合运算。实现时用互补微例验算：两个资源各覆盖目标一半时，∀q∃k应通过而∃k∀q应失败；三个目标在不同时段分别被覆盖时，总目标—秒可为正但同时覆盖交集可为空。正文公式、代码循环顺序和最终指标必须一致。

#### R3.44：全局目标保持的分解、独立子问题与后验合成审计

把大问题拆成若干子问题前，必须证明可行域和目标可分，或保留连接变量、共享容量、时间对齐和耦合约束。分别最大化各集合长度后再取交集，通常不最大化交集长度；分别求局部最短路径后拼接，也不一定得到含连接成本的全局最短。后验求和、取并或取交不能修复前面遗漏的协调。

若为计算效率采用分层启发式，应把独立子问题解称为候选生成器，再用原始全局评价器联合复评和协调精化；给可计算上界/下界、与联合小规模精确解的差距及分解失效条件。只有在目标可加、约束无共享且信息集独立时，独立最优才可直接合成为全局最优。

#### R3.45：验证器发现更优可行解后的候选支配审计

验证算法、基线或敏感性分支若找到目标更优且满足同一原始约束的解，它不仅是“误差不大”的验证，而是对当前最优性声明的直接反例。必须先用同一高保真评价器和数值精度复核两解；若更优解成立，应把它升级为当前最佳候选、重做交付与结论，或明确两个评价口径为何不可比。

报告启发式最优时应区分“已知最佳可行值”、可证明界和最优性差距。不能因主算法更快、解释更漂亮或差异只有几个百分点，就保留被支配方案并继续称其最优；验证的职责包括推翻而不只是佐证。

#### R3.46：目标参数、可识别组合与外部本构关系审计

先问观测方程直接识别的是题目所求参数，还是若干未知量的乘积、比值、积分或等效参数。若数据只约束光学厚度、有效刚度、总阻力或“强度×暴露”等组合，而其中一个因子仍可作为任意函数变化，则即使样本很多、拟合优度很高或增加两个相近工况，也不能声称各因子被唯一识别。

必须通过结构可辨识性、参数剖面/多起点、雅可比秩、后验相关或合成回归来检查。解除混淆所用的色散式、状态方程、校准样或先验必须注明外部来源、适用域和不确定度；若仍不可辨识，就报告可识别组合、区间或补充实验设计，不能把优化器返回的一组数当作唯一物理解。

#### R3.47：实体身份、界面端点与参数归属审计

为每个材料、群体、设备、节点和阶段状态建立唯一身份；每条界面、边、转移或作用关系都写清“从谁到谁”，参数也绑定到对应实体和状态。背景中同材质不同掺杂、同对象不同阶段、同节点不同方向，不得在推导中偷换成两种材料、两个独立对象或另一条边；反之，不同实体也不能因名称相近被强行共享参数。

用实体—关系表和最小路径回放核对正文、公式、代码及输出表。若某界面反射率、转移率或成本依赖两个端点，必须从这两个真实端点计算；任何替代实体只能作为明确的近似分支，并通过嵌套模型或误差界证明不会改变结论。

#### R3.48：全局拟合分数、结构残差与模型充分性审计

高R²或低总体RMSE可能由大幅基线、平台区、样本密集区或易拟合段主导，不能单独证明机理正确、参数准确或高阶效应不存在。必须在与目标机制相关的尺度上检查标准化残差、分频段误差、残差自相关/频谱、峰谷位置与留出数据；残差若仍保留与目标信号同频的周期、相位漂移或成组偏差，就是当前正演模型不足的证据。

比较复杂模型时使用同一原始数据、质量掩膜和留出方案，并惩罚新增自由度；预处理参数只能在训练部分确定。若另一模型或子带结论与主模型相差超过其不确定度，不能以取平均或“结果接近”代替冲突定位，必须查明模型误设、不可辨识、局部最优或数据域失配后再决定结论。

#### R3.49：观测与标签血缘、证据独立性及循环验证审计

先画从真实对象、传感器、算法输出到附件表、可视化视频、派生特征、校准值和标签的血缘图。两个文件、两种模态或两条结果若共享同一上游检测器、插值器、人工规则或校准常数，就共享系统误差；内容相符只能证明处理链自洽，不能按两份独立证据计数。由坐标渲染的视频、由同一预测生成的伪标签、同一原始记录的汇总表与明细表，都必须沿共同祖先合并有效证据量。

验证标签若由待评模型使用的同一输入、同一事件边界或同一校准样产生，就不是独立真值。把像素换算、规则评分、模型填补值或专家根据同一图像给出的代理值称为“实际结果”，再用它选择模型，会形成循环验证。应标注标签来源和误差，优先引入独立测量或外部留出；只能使用代理时，分别报告对代理的一致性、代理到真实目标的校准不确定度和无法验证的部分。

#### R3.50：事件状态机、持续性与边界不确定度审计

时序中的起跳、接触、启动、故障、峰值和恢复是状态转移，不等于某个导数首次越阈值。先写出前置状态、允许的转移顺序、主观测量、辅助观测量和最短持续时间；用滞回、连续若干帧/采样点和缺失质量门控排除噪声、另一次相似动作及单点尖峰。候选窗口若只覆盖“移动最快”或“曲线最像抛物线”的一段，还必须回到实体接触、约束释放或系统状态定义裁决真实边界。

事件时刻应给采样分辨率、标注分歧和检测误差形成的区间，并把边界向前后扰动后重算后续特征、模型与决策。若边界轻微移动就改变主要结论，应降低结论置信度或联合估计事件与参数；不得用平滑窗口、补值方向或事后目测逐样本改阈值，却仍把自动算法描述为统一规则。

#### R3.51：预测特征、可干预控制与可行反事实审计

高相关、高重要性或高预测贡献的变量不自动成为建议对象。逐变量区分不可改变属性、可长期改变状态、短期可控动作、结果发生后的中介/代理和测量伪差，并画出“动作—状态转移—机制中介—主目标”的响应链；年龄、身份、历史结果、派生评分或模型不可直接操纵的特征，不得被优化器当作控制量。

建议方案只在历史联合支持、物理/生理安全和真实执行幅度内改变可控动作，并用正向模型或可识别的干预效应重算主目标。预测模型沿高分方向得到的反事实若超出观测可行域、把相关关系当因果响应或同时要求互不兼容的特征，就只能列为待实验假设。交付时分开当前预测、可行改进区间、所需训练/控制动作、复测指标和停止条件，不能把理想特征拼接成必达点值。

### R4：资源与动作微型复演

用最小规模手算一个完整动作链，检查：

- 同一资源能否被两个动作同时占用；
- 动作开始、完成和状态更新发生在何时；
- “同时进行”究竟是真并行还是一个复合服务动作；
- 中途出现事件时，动作可否取消、改变或必须完成；
- 输出表记录动作开始、结束还是状态完成时刻。

这一步不求最优，只证明对运行机制的文字理解能够被第三人复现。

### R5：阶段与边界地图

所有动态题至少尝试划分：

- 初始化/冷启动；
- 过渡；
- 稳态或重复结构；
- 终端/截止时刻；
- 正常、异常、恢复。

若某些阶段确实可合并，必须由状态和动作集合相同来证明，不能默认全程同质。特别检查第一个对象、最后一个对象、截止时正在执行的动作和异常发生瞬间。

### R6：信息能力阶梯

为每类信息分别标记：

1. 当前直接观测；
2. 由当前状态和确定规律可计算；
3. 只有收到事件或反馈后才知道；
4. 未来随机，决策时不可知；
5. 通过额外检测、采样或成本才能获得。

若两种信息能力都符合题面，必须建立消融或分支比较。确定事件的可推算性不能与未来随机事件混在一起。

### R7：目标—代理—诊断三分账

把指标分成：

- **主交付目标**：题目真正要求优化或预测的结果；
- **求解代理**：为计算方便采用的损失、等待、距离、误差等；
- **诊断指标**：利用率、平衡度、稳定性、解释性等。

对每个代理指标构造一个可能冲突的反例：代理变好时，主目标是否可能变差？如果可能，代理不能直接替代主目标，只能用于下界、排序、同主目标下的次级比较或需要证明等价。

### R8：从交付物反推模型

从最终表格、图、文件、精度和评价要求逆推：

- 每个输出字段由哪个状态、事件或公式生成；
- 是否需要个体级日志、区间、概率、方案或仅汇总值；
- 主模型是否真的能够生成这些字段；
- 论文中的结论能否由交付结果复算。

不能出现“模型优化的是A，最终却凭经验填写B”。

### R9：同题高水平方案的对抗审计

独立理解和候选路线形成后，若能获得同题高水平论文、官方讲评或可靠复盘，执行以下操作：

1. 优先读取三份以上相互独立材料；不足三份则使用全部可得材料并声明证据边界；
2. 将比较严格拆成“读题理解”和“理解后的求解方法”两层；
3. 只在理解层比较对象、边界、阶段、信息、异常、交付物和歧义，不因对方算法高级就判其理解更好；
4. 每个差异分类为：我方遗漏、对方题外假设、原题真歧义、纯求解选择；
5. 我方遗漏必须先修通用机制，再修当前题；不能只记忆该题答案；
6. 对方方法只有在从新题事实可独立推出且通过验证时才进入求解候选。

同题审计是对独立路线的攻击测试，不取代独立读题，也不能把得奖论文当不可质疑的标准答案。

## 四、经验升级为通用规则的准入条件

从某道题发现的经验，只有同时满足以下条件才写回通用引擎：

1. 可以删除题名、对象名、常数和专用术语后仍清楚表达；
2. 它描述的是逻辑责任、信息结构、边界、验证或决策机制，而不是某个具体答案；
3. 能在至少两个不同结构场景中说明用途，或属于普遍的数学/逻辑合法性要求；
4. 有明确触发条件、禁用条件和验证方式；
5. 不会因为加入规则而强迫所有题使用同一种模型。

不满足者只留在相应题目的证据层，不进入通用协议。

## 五、进入求解前的理解证书

只有以下项目全部通过，才允许宣布“读题理解完成”：

- 原题、附件、图片、表注和输出模板完整；
- 核心术语作用域已复核；
- 会改变模型族的歧义已裁决或保留分支；
- 至少一个代表对象生命周期完整闭合；
- 每个显式给定的非平凡量已有模型去向或有证据支持其不相关；
- 过程时钟、记录时钟、决策时点和事件触发已经对齐；
- 文本/编码字段的可见语义已审计，计数和总量的暴露分母已对齐；
- 实验单元、测量单元、技术复测和生成数据已分开，样本量与验证划分没有伪重复；
- 运行顺序、批次、累计使用时长和预处理是否与处理因素混杂已经检查；
- 严格不等式的边界是否可取得已经说明，多因素候选位于可实现的联合支持域或明确标作外推；
- 题目指定标签、代理判定、专家结论和更晚参照标准没有被互换，记录级与主体级任务已分开；
- 首次潜在事件与首次观测阳性、检测失败及复检过程已分开，删失口径完整；
- 只有序数风险而无权重时没有伪造唯一最优，已提供保证水平、稳健区间或偏好敏感性；
- 移动对象的材料坐标、固定工位、动作完成位置和事件传播时延已经统一复演；
- 在线重排从真实计划版本和冻结前缀开始，未使用未来信息或虚构反事实初始方案；
- 优化时删除的固定/不可避免量已在最终绝对口径中恢复，并与可优化增量分列；
- 编号、行序和文件排列没有被无证据地当作时间/空间过程，序列模型通过了顺序语义与打乱检验；
- 阈值两侧无分离时没有承诺有限样本必然判定，原/备择方向、两类错误、无差异区和无结论规则明确；
- 返工/拆解/退货循环中的条件质量信念、混池状态、吸收概率与无限期望成本已经审计；
- 节点首达、边内状态、阈值跨越和整边失效没有混用，耗时动作已在原时空场中全程验证；
- 多源在同一容量/蓄积状态中联合推进并守恒，未用未经证明的取最早或时间等比例缩放；
- 传感器字段的字面事件、潜在状态和后继转移没有被混用，方向/编号已用附件字典与微型轨迹复核；
- 容量需求已由到达、服务、离开和并发占用生成，服务标准与现有容量缺失已传播为区间；
- 每个控制动作确实进入状态转移和目标响应，并在共同外生输入下与基线配对复演；
- 内生启停措施已区分意向与实际暴露，并审计邻接溢出、前趋势和系统总量；
- 最小动作链可由第三人按文字复演；
- 初始化、过渡、稳态、终端及异常阶段已检查；
- 每项决策的信息能力层级明确；
- 主目标没有被未经证明的代理指标替代；
- 每个交付字段都能追溯到模型状态或事件；
- 至少写出三条可能推翻当前理解的反证；
- 若存在同题高水平材料，已完成理解层的多材料对抗审计。

任一项未通过时，只能称为“暂定理解”，不能进入唯一模型路线。内部记录可以紧凑，但这些逻辑责任不得省略。
