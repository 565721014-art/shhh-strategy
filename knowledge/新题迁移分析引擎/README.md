# 新题迁移分析引擎

这是 Codex 面对任何新数学建模题时的首选入口。它不是往年题答案库，而是由58篇国一论文反推出的结构识别、模型组合、风险审计和验证系统。

## 读取顺序

1. 新题到来时直接从 [从这里开始_给Codex.md](从这里开始_给Codex.md) 进入。
2. 先读 [任意新题分析协议.md](任意新题分析协议.md)，独立建立事实层、结构指纹和母模型。
3. 用 [读题理解深度审计.md](读题理解深度审计.md) 检查替代解释、对象生命周期、阶段边界、信息能力、目标代理和输出可追溯性；没有理解证书不得锁定模型。
4. 用 [置信度_冲突与缺失信息协议.md](置信度_冲突与缺失信息协议.md) 淘汰误配和处理歧义。
5. 根据新题事实从 [模型组件与国一经验库.md](模型组件与国一经验库.md) 组合组件。
6. 用 [国一经验迁移矩阵.md](国一经验迁移矩阵.md) 寻找结构相似证据；禁止只按行业背景找旧题。
7. 用 [新题分析输出规范.md](新题分析输出规范.md) 输出结果。
8. 用 [未见新题压力测试.md](未见新题压力测试.md) 与 [对抗性误判测试.md](对抗性误判测试.md) 检查迁移和拒绝错误类比的能力。

## 与往年题教材的关系

`国一论文成品教材/` 是证据层，用于核对某个推理组件在国一论文中的实际用法；本目录是推理层，决定拿到新题时如何分析。正常情况下先用本引擎完成独立分析，之后才按需要读取少量证据章节，不能先找一道题照搬。

本引擎的“完整”含义是：58篇论文和23道原题的经验均保留在证据层，15个可迁移组件覆盖全部23题；新题层另有事实优先、置信度、冲突裁决、停止线和对抗性测试。它不承诺存在覆盖所有未来赛题的固定算法，而是保证遇到未知结构时不会把猜测伪装成结论。

版本3进一步把“事实是否覆盖”与“题意是否真正理解”分开。理解必须通过反事实解释、生命周期复演、阶段边界、信息能力和目标代理冲突测试；同题高水平材料只用于对抗审计，发现遗漏后优先修通用机制，不在引擎中记忆该题答案。
