# SHHH Strategy 轻量知识层

这是从完整本地档案生成的“文本优先”知识层，供技能自动检索。它保留题目卡、逻辑图、论文卡、分问分析摘录、23 题章节教材、迭代记录、版本协议和机器索引；默认不携带原始 PDF、Excel/CSV、逐页图片、整篇 OCR、完整解答文本、HTML 展示页、SQLite 二进制库或可执行文件。

## 为什么这样拆分

- 自动读题首先需要的是题意、分问交付物、变量关系、风险和可迁移经验，这些集中在 Markdown/JSON/TXT 中。
- 图片、公式、表格和附件仍是核验依据，但把它们全部放进默认包会增加下载、索引和上下文读取成本。
- 轻量层不是对原始证据的替代。需要核对公式、几何、表格或原题细节时，把完整档案路径通过环境变量接入：

```text
SHHH_STRATEGY_KNOWLEDGE_ROOT=C:\path\to\full\knowledge
```

查询脚本会优先使用显式传入的完整档案；未指定时使用本目录的轻量层。

## 目录约定

- `problems/`：23 道题的题目卡、逻辑图、题面文本和 58 篇论文卡/分析摘录。
- `国一论文成品教材/`：按题目组织的综合章节，适合按结构学习，不需要先读取整篇论文。
- `迭代训练/`、`model_versions/`、`新题迁移分析引擎/`、`AI时代读题训练/`：策略协议、停止门、风险审计和迁移记录。
- `index/`：去掉本机绝对路径后的 JSON/Markdown 索引；原始 SQLite 索引未打包。
- `heldout_evaluation/`：只保留文本/JSON/Markdown 的评测记录，原始测试附件仍在外部档案。
- `compact_manifest.json`：生成信息、文件清单、SHA-256 和有意排除项。

## 版权与使用边界

本目录是结构化检索层，不代表对外部论文、题面、数据附件或图片的再分发授权。技能仓库的 MIT 许可不自动覆盖外部原始资料。若公开传播，请仅保留你有权分享的摘要、索引和自写分析，并把完整原档案留在本地。
