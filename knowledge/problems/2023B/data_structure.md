# 2023B · 多波束测线问题 · 逻辑导航

## 母问题

海底地形上的多波束覆盖几何与测线规划

## 各问依赖

二维斜坡覆盖 -> 任意方向三维几何 -> 矩形海域测线设计 -> 实测地形分区与全覆盖规划

## 高频误读风险

- 水平宽度与坡面宽度混同
- 二维公式未经验证直接推广三维
- 平均重叠率掩盖局部漏测
