# 2023A · 定日镜场的优化设计 · 逻辑导航

## 母问题

光学效率仿真驱动的定日镜场布局与参数设计

## 各问依赖

太阳位置 -> 单镜多层效率 -> 场级时空积分 -> 固定尺寸布局优化 -> 可变尺寸与高度优化

## 高频误读风险

- 效率项重复相乘或遗漏
- 代表时刻代替全年积分无误差说明
- 优化变量不可施工
