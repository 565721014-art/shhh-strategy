# 2021C · 生产企业原材料的订购与运输 · 逻辑导航

## 母问题

供应商、订货、运输和库存耦合的多阶段资源配置

## 各问依赖

供货能力评价 -> 最少供应商集合 -> 周度订货计划 -> 转运分配 -> 成本/损耗/库存改进

## 高频误读风险

- 供应商评价与最终决策重复计权
- 以均值替代供货不确定性
- 跨期库存守恒遗漏
