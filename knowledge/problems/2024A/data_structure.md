# 2024A · 板凳龙闹元宵 · 逻辑导航

## 母问题

路径约束刚性链的运动、碰撞、调头与速度控制

## 各问依赖

龙头路径参数化 -> 后续把手位置/速度递推 -> 首次碰撞 -> 螺距可行性 -> 分段调头路径 -> 速度比例缩放

## 高频误读风险

- 把板凳当曲线弧段
- 板长与孔距混同
- 点距离替代矩形碰撞
- 整数秒检测漏掉首次事件
