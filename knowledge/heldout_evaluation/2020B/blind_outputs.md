## v3 快照约束回放

### 对题目的直接理解

题目从确定天气的单人资源路径优化，递进到未知天气的在线策略，再递进到存在拥堵惩罚和竞争收益的多人动态决策。核心状态为天数、位置、水、食物、资金；动作是移动、停留、挖矿和购买。

### 求解路线

1. 已知天气用有限期动态规划/整数规划，枚举路径、停留、挖矿和村庄补给，以终点现金加剩余资源半价回收最大为目标。
2. 对相同日—位置状态保留资金高、资源多的 Pareto 标签，减少状态数。
3. 未知天气用历史频率建立随机动态规划或滚动重规划，并设置保证能到下一补给点/终点的安全库存。
4. 多人情形把消耗、矿山收益和村庄价格按同地同动作人数修正，求联合最优或反复最佳响应。
5. 用逐日资源账本复核路线可行性。

### 回放的主要未闭合处

- “最佳”在未知天气而无概率分布时不可唯一识别，直接用经验频率可能引入题外信息。
- 多人题可能把社会总收益最优误当每个自利玩家的策略，未充分区分纳什均衡与合作分工。
- 到达村庄当日购买、挖矿到达日禁止、当日信息何时可用等边界时序未完全形式化。

## v26 冻结盲答

### 题目理解证书

1. 每天是一个严格事件序列：观测当天天气 → 依据当日可用信息选动作 → 支付该动作资源消耗 → 到达/停留节点并发生允许的购买或挖矿收益 → 记录日末状态。到达矿山当天不能挖；沙暴不能移动但可在矿山挖。
2. 起点只能在第 0 天购买一次，之后可回起点但不能再购；终点回收价是基准价一半。村庄“经过或停留时随时购买”允许到达后补给，但不能用尚未到达村庄才买到的水支撑当天路程。
3. 未知天气只给当前观测和很弱的“无沙暴/较少沙暴”信息，没有概率律和风险偏好，故不存在唯一期望最优策略；必须把鲁棒安全策略、给定信念下的期望策略和风险敏感策略分开。
4. 第 3 问已知天气但所有行动计划在第 0 天固定，是开环多人博弈；第 3(2)问中当天行动结束后才观察他人，所以他人第 t 日动作只能影响自己第 t+1 日决策，不能偷看同日动作。
5. 多人规则是非合作拥堵外部性：同路惩罚随 k 增至 2k 倍、同矿收益被 1/k 分摊、同村只要多人同购即涨至 4 倍。社会最优、纳什均衡与可协调分工通常不同，题面“玩家应采取”不足以自动指定合作目标。
6. 附件地图的邻接以公共边为准，不能按图上接近或公共顶点连边；异形图必须从边界逐条建邻接并人工复核。

### 数学闭合

单人确定型使用有限期资源约束时空网络。状态标签包含 `(t,node,water,food,cash,start_purchase_used)`；天气决定停留/行走/挖矿消耗，村庄购买为整数箱决策。终点价值为现金加剩余水食物半价。对同 `(t,node)` 的标签，只在资金不少、两资源不少且负重不高的严格支配关系下剪枝，避免错误合并现金与资源。

问题 2 建立按当天观测更新的 MDP/鲁棒动态规划。已知“10 天无沙暴”可形成有限情景集；“30 天较少沙暴”不是概率，先参数化为沙暴次数上界并给策略随上界变化。每步保留保证从当前点到最近补给/终点的可行安全集，再在安全集中最大化期望或最坏终值。

多人已知天气时，每名玩家的一条完整开环计划是策略，收益为其个人终值；通过候选路线—补给—挖矿计划生成后做最佳响应迭代/支持枚举，报告纯策略纳什、若无则混合或相关均衡，并另算合作总收益上界。在线多人时用部分观测随机博弈或滚动有限视野最佳响应，信念状态只包含截至上一日观察到的他人状态和行动。

### 关卡落地

- 第一、二关：用确定型 DP 生成 Result 的逐日动作/状态，并用独立账本验证。第一关异形 27 区，村庄 15、矿山 12；第二关 64 六边形区，矿山 30/55、村庄 39/62、终点 64。
- 第三、四关：分别使用“10 天无沙暴”鲁棒情景集与“30 天沙暴较少”的参数化策略，输出行动阈值而非伪精确唯一路线。
- 第五关 n=2、天气已知且无村庄，重点比较分流避开同路、错峰/分矿避免收益摊薄；所有计划第 0 天锁定。
- 第六关 n=3、仅知当天天气，在迷宫图上用上一日对手信息滚动响应；显式检查是否因追逐高矿收益产生拥堵循环。

### 验证与失败门

- 每条路线逐日核对负重、现金、水、食物和禁止动作，终值独立重算；DP 与小规模 MILP 交叉。
- 在线策略用同一批天气序列比较鲁棒/期望/风险策略，绝不在决策时读取未来天气。
- 多人结果报告单边偏离收益；没有零正遗憾不能称纳什均衡。若采用合作分工，必须说明协调与执行机制。
- 对购买发生在日初/日末的题意分支做微型复演；若分支改变可行性或最优值，正文显式声明采用口径。
