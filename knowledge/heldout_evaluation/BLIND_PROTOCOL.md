# 五题留出测试盲测协议

- 目的：比较冻结的 `v3_pre_23_iteration` 与 `v26_post_23_iteration_frozen` 对同一批未参与迭代题目的迁移能力。
- 测试题：2022A、2022B、2022D、2022E、2020B。
- 盲测边界：盲答阶段只允许读取官方原题和官方附件；任何解答、论文、讲评、代码仓库中的解题内容全部锁定。
- 回放含义：v3 是在当前执行器中受 v3 快照规则约束的“快照回放”，不是重新训练出的独立模型；v26 使用冻结快照，测试期间不得修改引擎。
- 产出顺序：原题/附件完整性核验 → v3 盲答 → v26 盲答 → 文件哈希固化 → 解锁论文 → 统一量表复评。
- 双层评析：每题必须分别评“题目理解”和“理解后的求解方法”，不得用模型名称数量代替理解质量。
- 论文地位：获奖论文只作为覆盖面、正确性和表达的参照，不作为真值；若盲答方案更严谨，应保留盲答结论。
- 评分量表：U 题意与量词、M 数学闭合、I 信息时序/可识别性、D 附件与数据语义、V 验证/失败门、T 可交付性，每项 0～5；解锁前分数仅为预注册自评，解锁后由证据复评。
- 冻结规则：每题的 `blind_outputs.md` 一经写入便不因论文内容重写；后续评价写入独立文件。
