This file is the mandatory low-cost scan for the V27.2 structural library. A gate is dormant until the statement, an attachment, mathematics, or independently reproduced evidence triggers it. Read the linked gate group completely when any trigger in that group is live. Do not activate a gate from a historical analogy alone.

## Routing discipline

1. Record each activated gate number and its exact trigger in the analysis state. A keyword match is only a clue; the trigger must be tied to a deliverable, source fact, mathematical property, or reproduced pattern.
2. Read every detailed file whose group contains an activated gate. Apply only its relevant gates; nearby gates do not activate automatically.
3. If the source is incomplete, keep the affected gate provisional and stop dependent claims instead of inventing a trigger.
4. Before declaring `route_executable`, scan all 18 gate names below without reopening unrelated detail. If the route or reread reveals a new trigger, read that gate group and regress the route.
